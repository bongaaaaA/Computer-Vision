# 🛰️ Satellite Semantic Segmentation

## 📌 Project Overview
This project focuses on **Semantic Segmentation for Satellite Images**, where each pixel in the satellite image is classified into a specific land-cover class (e.g. roads, buildings, vegetation, water, etc.).

The main goal is to automatically extract meaningful regions from satellite imagery using **Deep Learning–based Semantic Segmentation models**.

---

## 🧠 Semantic Segmentation Architecture
The project is based on a **Deep Learning Semantic Segmentation architecture**, commonly used in computer vision tasks such as satellite image analysis.

**Architecture highlights:**
- Encoder–Decoder structure  
- CNN-based feature extraction  
- Pixel-wise classification  
- Trained on satellite imagery data

The model outputs a **segmentation mask** where:
- Each pixel represents a predicted class
- Colors indicate different land-cover categories
